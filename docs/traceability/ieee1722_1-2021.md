# Traceability — IEEE 1722.1-2021 (ATDECC: ADP / ACMP / AECP+AEM)

Part of [`docs/SPEC_TRACEABILITY.md`](../SPEC_TRACEABILITY.md). Legend and
conventions live there. Clause numbers are from IEEE Std 1722.1-2021 (verified
against the local standards PDF `$STANDARDS_DIR/1722.1-2021.pdf` — **the
directory is the local standards directory; `$STANDARDS_DIR` itself is unset, which is
what led two rounds to conclude the text was paywalled and to paraphrase
instead of quote. Extract with `pdftotext -layout`. TRAP: the hexadecimal
*value* column of Table 7-1 extracts mangled — leading digits dropped, letter
glyphs shifted by one, so LOCALE reads `D16` where the value is `0xC`. Take
descriptor type codes from the intact *clause* column: AUDIO_CLUSTER is the
7.2.16 row = `0x0014`, AUDIO_MAP the 7.2.19 row = `0x0017`. Quote prose, verify
numbers.**). Milan v1.2
overrides/deltas are NOT repeated here — see
[`milan-v12.md`](milan-v12.md); a row marked *(Milan overrides)* means the
1722.1 base behavior is intentionally replaced and the Milan file carries the
authoritative row.

Verification tokens: `RTL <dir>` = `tb/verilator/<dir>`; `BENCH` = bench behave
recreation feature; `SILICON` = wire-proven on ARTY/AX7101 (see
[`docs/MILAN_COMPLIANCE_GAPS.md`](../MILAN_COMPLIANCE_GAPS.md) /
[`docs/findings/BENCH_TOPOLOGY.md`](../findings/BENCH_TOPOLOGY.md)); `tsn_gen:` =
YAML model under the local tsn-gen checkout's `protocols/` consumable by packet_gen
(generate + fuzz + decode on the wire). `NO MODEL` = tsn_gen model to author.

## Contents

- **[1. ADP — discovery (Clause 6)](#1-adp--discovery-clause-6)** — 17 rows, every one covered and no model gap left. The rows worth reading are the traps: `entity_id` sits at wire byte 18 (not 16), and la_avdecc *expects* `available_index` to bump per PDU where 6.2.2.15 says it must not.
- **[2. ACMP — connection management (Clause 8)](#2-acmp--connection-management-clause-8)** — Only PDU format, addressing and sequencing are claimed here; Milan 5.5 replaces the three base state machines, so 8.2.3/4/5 point at the Milan file instead. Carries the corpus's largest single gap: there is **no tsn_gen ACMP model at all**, named as the highest-value one to author.
- **[3. AECP + AEM (Clause 7 model/commands, Clause 9 transport)](#3-aecp--aem-clause-7-modelcommands-clause-9-transport)** — The long one, in three tables: Clause 9 transport, the static descriptor ROM, and the implemented command set. Where to look for what is *not* green: SET_STREAM_INFO takes only `MSRP_ACC_LAT`, ADDRESS_ACCESS commands are not admitted at all, and 0x4B `GET_DYNAMIC_INFO` is the row where silicon diverged from the testbench four separate times.
