# Diagram catalog

The standard for every diagram in this repo: an easily-modifiable **master**
(a `.drawio` file, usually generated by a checked-in `*.gen.py`/`diag_*.py`
script) plus **committed renders** (`.svg`/`.png`). Edit the master (or the
generator) and re-render; **never hand-edit a render**. For `.drawio`
masters the render paths are: draw.io/diagrams.net desktop export, or the
repo's minimal headless renderer
`hdl/ieee17221/aecp/doc/atdecc_architecture.render.py <file.drawio>`
(verify its output - it does not cover HTML-formatted labels). `.png` from
`.svg`: `rsvg-convert`.
