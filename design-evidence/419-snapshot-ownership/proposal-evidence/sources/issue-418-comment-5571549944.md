# Issue #418: late record write before firmware ACK

**Reproduced in a component co-simulation against the real, unmodified backend RTL.** A normal backend record write completed two backend clock edges before firmware ACK. ACK cleared dirty although the acknowledged flash slot still held the older binding. The production firmware then ran its normal service loop for another 1,200 modeled milliseconds without starting another commit. The no-intervening-change and exact-cycle controls both passed.

## Results and causal timelines

The firmware is triggered through its **ordinary idle dirty-service path**, `milan_baremetal.c:881-902`, not the `milan_nvm commit` console command. Initial normal record writes make real RTL dirty; service waits its provisional 1,000 ms debounce and calls `nvm_commit("dirty")`.

|---|---|---|---|---|
| No intervening change | None; initial older record completed before the bracket | initial write 273; ACK 281 | `(1,0,0)` | One ACK total, no extra erase or program; correct |
| Earlier write | ERASE grant 280, terminal 394; WRITE grant 395, terminal 537 | write 537; ACK 539, gap 2 | `(1,0,0)` | One ACK total, sequence 1; newer record remains only in DDR |

## Contract and reachability

The result contradicts the meaning assigned to dirty in `docs/design/SAVED_STATE_FASTCONNECT.md:948`: the image holds committed changes no slot holds. Its section 9.3 row at `:1053` describes `(backed=1,dirty=0,stale=0)` as everything committed being in a slot. The earlier-write case produces that row with a completed newer binding only in DDR. It also exposes the missing premise in the firmware ACK comment at `milan_baremetal.c:818-824`.

The RTL follows its documented per-cycle formula at `KL_nvm_backend.sv:485-488` and design section 9.2 `:1015`: a change wins on the exact ACK cycle, otherwise ACK clears dirty. The same-cycle control confirms this. The defect is in the broader transaction contract: ACK carries no image generation or snapshot identity, so the correct per-cycle formula cannot distinguish older-image ACK from a newer completed change.

No inspected current contract prevents these concurrent writes. `commit_busy_r` is controlled by the firmware start/ACK deadline machine at backend `:518-526`; device command acceptance at `:605-627` tests request, image configuration and span validity, without testing the commit bracket. Firmware checks `NVM_RD_DEV_BUSY | NVM_RD_COMMIT_BUSY` once before starting a commit at `milan_baremetal.c:894`; it does not reserve the record area. The parent directly connects the donor device face to this backend at `hdl/milan/KL_pp_shadow.sv:923` and `:1147`. The donor binding manager has no firmware-commit-busy input on its manager face at `protocol-processor/hdl/acmp/KL_acmp_nvm_shadow.sv:111-147`, and the downstream port has no such input on its device face at `protocol-processor/hdl/packet_engine/KL_pp_nvm_port.sv:74-90`.

The diagnostic uses an external producer BFM in place of the upstream donor port/manager. Its ERASE-then-WRITE envelope and framing are ordinary production interfaces, documented at `protocol-processor/hdl/packet_engine/KL_pp_nvm_port.sv:14-40` and emitted by `:354-372`. No privileged/debug CSR, forced internal register, changed RTL source, or always-asserted dirty override is needed. The initial write is likewise a normal device transaction. A bound started/stopped update is an existing persisted binding field, projected by `protocol-processor/hdl/acmp/KL_acmp_nvm_shadow.sv:252` and serialized at `:404`. This establishes backend acceptance and firmware consequence under a permitted external schedule; it does not prove the exact waveform of a particular received AECP command through the full donor pipeline.

## Timing and coverage limits

- The backend is transaction-clocked: clocks advance during CSR and device/memory operations, not during every elapsed host-model nanosecond. `rtl_ns` is backend cycle count times 20 ns and is **not** a synchronized physical timestamp for `host_ns`. The test proves edge ordering and real RTL response, not CPU instruction timing, DDR arbitration latency, timer deadlines, or measured probability of the race on silicon.
- The earlier-write scheduler runs the entire ERASE/WRITE synchronously at the post-verification sequence-store hook, effectively pausing firmware between CSR operations for 258 backend edges. This proves the contract race under that permitted ordering. It does not prove that a complete real device operation fits the actual SoC interval from the final byte comparison to ACK. The exact-cycle control likewise deliberately delays accepting the modeled ACK until WRITE completion. No actual RV32I CPU, LiteX CSR bridge, memory arbiter, SPI device, donor NVM port or ACMP shadow is instantiated. These are the boundaries an independent reviewer should challenge if claiming full-system timing reachability.
- Source-derived, unexecuted wider window: `nvm_slot_matches` at `milan_baremetal.c:800-808` compares bytes in ascending order and does not revisit them. Once binding bytes 162 through 189 have been compared, 2,506 byte pairs, indices 190 through 2,695, remain. A complete change confined to the already-compared binding could therefore evade the remaining comparison and still precede ACK. This follows from the C loop and record placement, but no case here schedules that overlap or measures how many backend edges those remaining comparisons take on the RV32I SoC. The probe does not establish that a full ERASE/WRITE fits that window either.
- The decisive earlier-write result does not depend on the old host dirty model: each status read exposed to firmware takes dirty/backed/stale/bracket from the real RTL. The host boot-walk and wall-time/liveness counters remain modeled and are not RTL timer evidence.
- Only the shipping 1x1 geometry and this late-completion interleaving are exercised. No power loss, invalid record, timeout/abort, erase-failure, or complete #70 acceptance claim is made. Existing controls preserve the valid unchanged commit and erased positions for this configuration.

// SPDX-License-Identifier: CERN-OHL-W-2.0
// Issue #418: temporary external device/DRAM scheduler around unmodified RTL.
#include "VKL_nvm_backend.h"
#include "verilated.h"
#include <cstdint>
#include <cstdio>
#include <cstdlib>
#include <cstring>
#include <memory>
#include <vector>
extern "C" {
#include "nvm_host.h"
}

namespace {
constexpr uint32_t kBase = 0x40000000;
constexpr uint64_t kClockNs = 20; // 50 MHz backend clock, separate from host time.
std::unique_ptr<VKL_nvm_backend> dut;
uint64_t cycles = 0;
uint64_t write_done_cycle = 0;
uint64_t ack_cycle = 0;
unsigned accepted = 0;
unsigned bytes_committed = 0;
struct Write {
  bool busy = false;
  int delay = 0;
  uint32_t addr = 0;
  uint64_t data = 0;
  uint8_t strb = 0;
  uint64_t accept_cycle = 0;
} wr;

[[noreturn]] void fail(const char *why) {
  std::fprintf(stderr, "RTL DIAGNOSTIC ERROR: %s\n", why);
  std::exit(2);
}

uint8_t *area() { return nvm_host_ddr + NVM_HOST_IMAGE_OFF + 40; }

void edge() {
  dut->clk_i = 0;
  dut->mem_wr_ready_i = !wr.busy;
  dut->mem_wr_done_i = wr.busy && wr.delay == 0;
  dut->mem_wr_err_i = 0;
  dut->eval();
  const bool take = dut->mem_wr_valid_o && dut->mem_wr_ready_i;
  const bool finish = dut->mem_wr_done_i;
  if (dut->dev_err_o) fail("device operation reported err");
  if (dut->dev_done_o && dut->dev_op_i == 1) write_done_cycle = cycles + 1;
  if (dut->csr_sel_i && dut->csr_we_i && dut->csr_addr_i == 4 &&
      (dut->csr_wdata_i & 2)) ack_cycle = cycles + 1;
  if (finish) {
    std::printf("BRIDGE accept_cycle=%llu commit_cycle=%llu addr=0x%08x strb=0x%02x data=0x%016llx err=0\n",
        (unsigned long long)wr.accept_cycle, (unsigned long long)(cycles + 1),
        wr.addr, wr.strb, (unsigned long long)wr.data);
    for (unsigned n = 0; n < 8; ++n) {
      if (!(wr.strb & (1u << n))) continue;
      if (wr.addr < kBase || wr.addr - kBase + n >= 0x10000 - 44)
        fail("memory write outside staged record area");
      area()[wr.addr - kBase + n] = uint8_t(wr.data >> (56 - 8 * n));
      ++bytes_committed;
    }
    wr.busy = false;
  } else if (wr.busy) {
    --wr.delay;
  }
  if (take) {
    if (wr.busy) fail("bridge accepted overlapping write");
    wr = {true, 2, dut->mem_wr_addr_o, dut->mem_wr_data_o,
          uint8_t(dut->mem_wr_strb_o), cycles + 1};
  }
  dut->clk_i = 1;
  dut->eval();
  ++cycles;
  dut->clk_i = 0;
  dut->eval();
}

void drive_csr(unsigned addr, uint32_t value) {
  dut->csr_sel_i = dut->csr_we_i = 1;
  dut->csr_addr_i = addr;
  dut->csr_wdata_i = value;
}
void clear_csr() { dut->csr_sel_i = dut->csr_we_i = 0; }

uint32_t status() {
  const auto old = dut->csr_addr_i;
  dut->csr_addr_i = 3;
  dut->eval();
  const uint32_t result = dut->csr_rdata_o;
  dut->csr_addr_i = old;
  dut->eval();
  return result;
}

void log(const char *tag) {
  const uint32_t s = status();
  std::printf("RTL tag=%s cycle=%llu rtl_ns=%llu status=0x%08x backed=%u dirty=%u stale=%u bracket=%u dev_busy=%u change_pin=%u\n",
      tag, (unsigned long long)cycles, (unsigned long long)(cycles * kClockNs), s,
      (s >> 6) & 1, (s >> 8) & 1, (s >> 9) & 1, (s >> 10) & 1,
      (s >> 4) & 1, unsigned(dut->change_i));
}

void command(unsigned op, unsigned rid, const std::vector<uint8_t> &frame,
             bool coincident_ack) {
  dut->dev_req_i = 1;
  dut->dev_op_i = op;
  dut->dev_region_i = rid;
  dut->dev_offset_i = 0;
  dut->dev_len_i = op == 2 ? 0 : frame.size();
  dut->dev_wvalid_i = 0;
  edge();
  if (!dut->dev_gnt_o) fail("backend did not grant idle device request");
  std::printf("DEVICE grant_cycle=%llu op=%u record_id=0x%02x offset=0 len=%u bracket=%u\n",
      (unsigned long long)cycles, op, rid, unsigned(dut->dev_len_i),
      (status() >> 10) & 1);
  ++accepted;
  dut->dev_req_i = 0;
  size_t sent = 0;
  for (unsigned guard = 0; guard < 10000; ++guard) {
    dut->dev_wvalid_i = op == 1 && sent < frame.size();
    if (dut->dev_wvalid_i) dut->dev_wdata_i = frame[sent];
    dut->eval();
    const bool took = dut->dev_wvalid_i && dut->dev_wready_o;
    const bool done = dut->dev_done_o;
    if (done && coincident_ack) {
      if (op != 1) fail("ACK incorrectly scheduled on erase completion");
      drive_csr(4, 2);
      log("write_done_and_ack_preedge");
    }
    edge();
    if (took) ++sent;
    if (done) {
      dut->dev_wvalid_i = 0;
      clear_csr();
      if (op == 1 && sent != frame.size()) fail("incomplete record byte stream");
      if (coincident_ack && write_done_cycle != ack_cycle)
        fail("coincident stimulus missed exact edge");
      std::printf("DEVICE terminal_cycle=%llu op=%u record_id=0x%02x bytes_sent=%zu done=1 err=0\n",
          (unsigned long long)cycles, op, rid, sent);
      return;
    }
  }
  fail("device request timed out");
}
} // namespace

extern "C" void rtl_init(void) {
  dut = std::make_unique<VKL_nvm_backend>();
  dut->rst_n = 0;
  dut->change_i = 0;
  dut->dev_req_i = dut->dev_wvalid_i = dut->dev_rready_i = 0;
  dut->mem_req_ready_i = dut->mem_rsp_valid_i = 0;
  dut->mem_rsp_data_i = 0;
  dut->mem_rsp_last_i = 1;
  dut->mem_rsp_err_i = 0;
  clear_csr();
  for (int n = 0; n < 8; ++n) edge();
  dut->rst_n = 1;
  edge();
}

extern "C" void rtl_csr_write(unsigned addr, uint32_t value) {
  // Translate host pointer to a fixed, aligned simulation address only.
  // Geometry, length, map tables and all other control bits come from firmware.
  drive_csr(addr, addr == 0 ? kBase : value);
  if (addr == 4 && (value & 2)) log("firmware_ack_preedge");
  edge();
  clear_csr();
  if (addr == 4 && (value & 2)) {
    log("firmware_ack_postedge");
    std::printf("RTL ack_cycle=%llu preceding_write_done_cycle=%llu gap_cycles=%llu\n",
        (unsigned long long)ack_cycle, (unsigned long long)write_done_cycle,
        (unsigned long long)(ack_cycle - write_done_cycle));
  }
}

extern "C" uint32_t rtl_status(void) { return status(); }
extern "C" uint64_t rtl_cycles(void) { return cycles; }
extern "C" void rtl_log(const char *tag) { log(tag); }
extern "C" void rtl_finish(void) { dut->final(); dut.reset(); }

extern "C" void rtl_write_record(unsigned image_offset, const uint8_t *data,
                                  unsigned len, int coincident_ack) {
  if (len < 8 || data[0] != 0x17 || data[1] != 0x22) fail("unframed diagnostic record");
  const std::vector<uint8_t> frame(data, data + len); // immutable stimulus copy
  const unsigned rid = frame[3];
  const unsigned first = bytes_committed;
  const unsigned ops = accepted;
  log("record_update_before");
  std::printf("RTL record_id=0x%02x framed_bytes=%u image_offset=%u start_cycle=%llu\n",
      rid, len, image_offset, (unsigned long long)cycles);
  command(2, rid, {}, false);
  command(1, rid, frame, coincident_ack);
  if (std::memcmp(nvm_host_ddr + NVM_HOST_IMAGE_OFF + image_offset,
                  frame.data(), len) != 0) fail("backend output bytes differ from stimulus");
  if (accepted - ops != 2 || bytes_committed - first != len * 2)
    fail("expected one full-region erase and one full-record program");
  log("record_update_after");
  std::printf("RTL completed_record_id=0x%02x device_ops=%u committed_bytes=%u write_done_cycle=%llu ack_cycle=%llu\n",
      rid, accepted - ops, bytes_committed - first,
      (unsigned long long)write_done_cycle, (unsigned long long)ack_cycle);
}
