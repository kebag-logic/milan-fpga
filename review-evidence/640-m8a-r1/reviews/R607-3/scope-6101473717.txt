**Usable bytes.** A RAMB36 gives 4,096 byte-addressable bytes, so 50 tiles hold 204,800 B and 224,000 B needs 55. The ledger's 4.5 KB per tile counts parity bits.

**As mapped.** Each memory is LiteX's `wishbone.SRAM` alone, synthesised out of context on `xc7a100t-fgg484-2` with `AreaOptimized_high`, ROMs initialised from the image. Default inference rounds each memory to a power-of-two depth: a 204,800 B memory maps to 64 RAMB36. Every case used 0 RAMB18. A `ram_decomp` variant was not run.

**BIOS ROM and SRAM reuse at `e8454e27`.** 16 + 2 = **18 RAMB36, 0 RAMB18**. The ledger's extra RAMB18 is the 49-byte SoC identifier memory, which stays in either placement.

**Ledger.** `87.5 - 6.5 + 6 - 18 + 55 + 2 = 126` tiles at the floor, and 135 as mapped, against the 121.5 ceiling before the conditional release.

**Also absent at this base.** The service, boot and route proofs need F-INT PR 2:

**All-fabric without DDR3 (measurement only).** Compacted, the processor window is 14,792 B (4 RAMB36) at 1x1 and 46,640 B (12 RAMB36) at 8x8.
