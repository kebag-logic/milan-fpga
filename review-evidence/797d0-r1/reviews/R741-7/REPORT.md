That moves the page's own line count and the totals, so `--check` exits 1 on an otherwise exact export.
- **Reproduction:** `receipts/probe_gitless_pycache.diff` shows 7 differing lines. The same export without bytecode returns rc 0 (`receipts/probe_control_unedited.txt`). The Git path ignores the cache, and `--check` returns rc 0 with it present (`receipts/inv_check_head_with_pycache.txt`).
- **Impact:** none on any current CI path. Only `docs-gates-0`, a Git checkout, runs the inventory gate, and `docs-check-no-git` does not. The risk is to a future Git-less caller, or a local export, that runs other scripts first.
- **Optional outcome:** have the walk skip `__pycache__` and bytecode, or skip ignored paths. Add a selftest control that plants a cache directory in a Git-less fixture.
