**R497-2-F1 - MAJOR - Conformance, RTL, Robustness, Tests - Restart can erase an owed ENTITY_DEPARTING.**

Artifacts: `sw/firmware/ctrl/adp/adp.c:96` (the single pending slot), `:156` (re-enable), `:217` (new timer expiry), `:248` (poll); `sw/firmware/ctrl/test/test_adp.c:275`; `scripts/restart_probe.c`; `receipts/restart-probe.log` and `.rc`.

Authority/evidence: F0 requires ENTITY_DEPARTING, and round-2 items 4 and 6 require reliable pending output and shutdown/restart wire behavior. The implementation's cited Milan v1.2 5.6.3.5.8/5.6.3.5.11 and public [DEPARTING ruling](https://github.com/kebag-logic/milan-fpga/pull/668#issuecomment-5994972330) require the departure to carry the current index; the next start begins with AVAILABLE index zero. The public enable API states no precondition requiring callers to wait for pending output before enabling again.

Reproduction: advertise once, saturate the transmit path, disable, enable again while DEPARTING remains owed, then expire the new startup timer before TX recovers. Shutdown saved DEPARTING index 1. The expiry calls `advertise()`, whose failed `send()` replaces `ADP_PENDING_DEPARTING` with `ADP_PENDING_AVAILABLE` and index zero. Once room returns, the next frame is AVAILABLE index zero; no DEPARTING was committed. This occurs both through the core's public ports and through the mailbox driver, model timer and event loop. The probe reports 8 checks, 3 failures, exit 1. Its control, deferred shutdown without intervening restart, passes.

Impact: ordinary disable/re-enable ordering under backpressure silently drops a required shutdown message. Keeping the loop awake cannot recover the overwritten obligation. Existing A13 sends the deferred departure before re-enabling, so its passing result does not cover this overlap. RTL attribution is to the protocol/firmware output-state architecture, not a defect in the registered bus adapter.

Required outcome: preserve and serialize the owed departure, including its shutdown index, across restart and timer expiry. A new AVAILABLE must not replace it. Preserve normal restart, retry and timer behavior without an undocumented API restriction.

Verification: add the overlapping shutdown/restart/full-ring case to the normal firmware tests, with a named mutation that discards or overwrites the owed departure. Require departure index 1 followed by the restarted AVAILABLE index 0, eventual WAITING/TMR_ADVERTISE, and no stranded output. The packet's probe is a reproducible failing check against the unchanged source.
