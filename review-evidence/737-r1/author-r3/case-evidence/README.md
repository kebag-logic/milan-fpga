The full and leg JSON files are byte copies of completed case receipts. Each comparison was rerun through scripts/ci_case_receipts.py against the raw stdout retained in scratch. The fresh inventory is derived from the current driver. stdout-inventory.json records each raw output file, size and SHA-256; raw logs remain in scratch, including outputs above the 200 KB handoff limit. comparison-summary.json records real production-reader refusal of a case dropped from every claim and a changed stdout with its digest recomputed. No simulation result was synthesized for these comparisons.
