## Findings per area (not fixed here unless marked; each needs its own Issue)

Builder code (`sw/builder/endstation_builder.py`, 7 findings):

1. Unknown keys are dropped silently in 14 mappings (top level, `entity`, `board`, `clocking`, `clocking.crf_output`, `audio_interface`, `cluster_mapping`, `streams`, each stream entry, `srp`, `srp.timers_ms`, `srp.tspec`). A misspelt optional key keeps its default. Generated evidence: the unknown-key table.
2. Without `--write-fragment`/`--write-rtl` the CLI prints `wrote configs/generated/sweep_opts_<board>.sh` but `_write_shape_copies` (5925-5935) does not write it: `build()` returns the path unconditionally (5978) and `main()` prints every returned path (6064-6067). Receipt `example/07`.
3. `entity.vendor_name` has no length check (`_load_entity` 3741-3743 checks name, serial, group and firmware version only); 200 octets reach the overlay. Key-reference row.
4. Two limits for one AEM string field: `entity.*` strings refuse above 63 octets (3742, "AEM cstr64"), `names.*` and `entity.locale` accept 64 (`_aem_string`, `AEM_STRING_BYTES`). IEEE 1722.1-2021 7.2 strings are 64 octets with no NUL needed when full.
5. `framer_wire_channels` returns an odd width for an odd talker count (3 gives 3) against its own docstring, "Even, WIRE_CHANS_MIN..MAX" (1160-1161, 1189-1190).
6. Integer keys converted with `int()` (`board.constraints.uart_baudrate`, `sys_clk_hz`, `num_queues`, others) raise an unhandled `ValueError` on a non-integer, not a named `ConfigError` (`_load_board` 3906-3915). Key-reference row shows "no named refusal".
7. Boolean keys read with `bool()` accept any value (`gtx_tx_invert`, `floorplan`, `pools.pilot`, `fabric.loopback_lane`, `soc.timing_opt`): `floorplan: "no"` reads true.
