The scripts take explicit source and work directories. Keep all disposable files under `scratch/`. Supply GoogleTest/GMock 1.14.0 through `CMAKE_PREFIX_PATH` and `PKG_CONFIG_PATH`, Clang 18 for the source lexers, and the documented host and RV32 dependencies. The static-analysis distribution version is 18.1.3; version 23.1.1 produces the separately recorded inherited padding diagnostic.

Export the exact source with `git archive 0868387deab21bd0db414424f306c7ea62498e29` into `scratch/tree`. `run_commands.py` runs a JSON array of `{name, argv, cwd}` entries concurrently in the foreground and records logs, return codes and elapsed time. Use it to run independent campaigns concurrently. The packet's plan receipts show the actual invocations; `${SOURCE}`, `${PACKET}` and `${SCRATCH}` are relocation placeholders.

Run `escape_probe.py --tree scratch/tree --work scratch/escape --jobs 4` unchanged. Run `physical_removal.py --tree scratch/tree --work scratch/physical-0 --plants NAME,NAME,...` unchanged with all 16 new `AcmpFresh` plants (the 15 `dafresh-` core plants plus `x-zero-never-expires`). That script has no jobs option and uses eight two-job builds. The generated-configuration plant belongs to the entity binary; `complete_suites.py --work scratch --jobs 4` supplies its physical deletion and verifies all 17 plants across all eight binaries, including exact source differences and fresh XML registration.

Run the repository's `validate.py --work scratch/validation --jobs 4` and `baremetal.py --work scratch/rv32 --jobs 4` concurrently. Repeat the RV32 gate on an exported `1ba2735` base. Measure loadable image bytes with the cross toolchain's `objcopy -O binary`, including alignment bytes; do not compare debug ELF container sizes. The local full runner intentionally retains its original nonzero result. The separately repeated static gate with a complete distribution SDK passed. Hosted receipts supply the graph gate and the complete 28-entry run.

`job_limiter.py` can be copied under compiler executable names in a temporary `bin` directory. `REVIEW_LIMITER_ROOT` names a scratch directory with `tool-paths.json` mapping each name to its actual executable and an existing `job-slots` directory. It limits actual compiler/analyzer invocations to 16 and runs the internally parallel static checker with one worker. `REVIEW_CLANG18_LIBRARY_PATH` optionally supplies the extracted SDK's shared-library directory. This scheduler changes no source or assertion.

`audit_evidence.py` checks a downloaded quality artifact and the published author packet against the source checkout. It verifies the 98-file source snapshot, 28 gate results, 365 mutation results with 394 named assertion needles, and the author's 17 complete-suite physical-removal proofs. Hosted archive SHA-256 digests are in `receipts/hosted-provenance.json`; the public evidence commit and blob identities are in `receipts/public-evidence-fetch.json`.

`rtl_edges.py` uses the scoped processor inputs identified in `receipts/processor-inputs.json`, an explicitly supplied 5.050 executable, and `--jobs 2`. It accepts the unchanged suite at exactly 15000 ms and rejects its deliberately incorrect closure expectation at 14999 ms. This is a boundary control, not a production-source mutation.

`verify_source.py` checks every tracked byte and mode, index tree, HEAD, status and core gitlinks. `collect_receipts.py` preserves raw outcome contents while replacing machine-specific path prefixes for publication. `receipts/receipt-provenance.json` records both original and published SHA-256 values; original logs remain in unpublished scratch. No output under `scratch/` is publishable.
