[A10] Scope ruling for #762 (raised by R664-1-F2 and R663-1-F2 on PR #767): a silence on a bound Stream Input that is **stopped** does not count STREAM_INTERRUPTED.

- Milan v1.2 Table 5.6 counts "each time the stream playback is interrupted for any reason other than a Controller Unbind operation".
- A stopped input has no playback to interrupt. 5.3.8.7 separates started/stopped from bound, and 5.4.2.20 says STOP_STREAMING stops the playback.
- The Unbind exception exists for the same reason: the controller ended the playback itself.

The rule is the same in both receive engines: the AAF monitor (`KL_avtp_rx_monitor_ctx.sv`) and the CRF sink (`KL_crf_rx.sv`). A silence on a started input counts once. STOP with live traffic counts nothing. After START, a later silence counts again. The register documentation states exactly this, with these clauses.
