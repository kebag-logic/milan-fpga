**Behaviour.** The DUT's AAF stream follows a CRF media clock on its Stream Input. Its mr bit toggles when:
- the CRF stops;
- the input is unbound;
- the CRF's own mr toggles.

It does **not** toggle when the CRF comes back, or when the input is bound again. Over 80,000 frames in each window, there were 0 toggles.

**Required.** IEEE 1722-2016 4.4.4.3: mr indicates that there has been a change in the source of the media clock, and toggles each time a media clock restart is needed. The media clock returning to the CRF is such a change.

**Source.**
- `hdl/milan/milan_datapath.sv:3243-3246`: only the CRF lock-loss edge requests a restart, and the re-lock edge does not.
- See also `hdl/ieee1722/avtp/KL_media_clock_restart.sv:168-179`.

**Done when:**
- the selected CRF's lock-gain edge also requests a media clock restart, so mr toggles once on the return;
- a simulation case and a planted mutant cover both edges;
- the suites pass.

[A10] Scope ruling for #762 (raised by R664-1-F2 and R663-1-F2 on PR #767): a silence on a bound Stream Input that is **stopped** does not count STREAM_INTERRUPTED.

- Milan v1.2 Table 5.6 counts "each time the stream playback is interrupted for any reason other than a Controller Unbind operation".
- A stopped input has no playback to interrupt. 5.3.8.7 separates started/stopped from bound, and 5.4.2.20 says STOP_STREAMING stops the playback.
- The Unbind exception exists for the same reason: the controller ended the playback itself.

The rule is the same in both receive engines: the AAF monitor (`KL_avtp_rx_monitor_ctx.sv`) and the CRF sink (`KL_crf_rx.sv`). A silence on a started input counts once. STOP with live traffic counts nothing. After START, a later silence counts again. The register documentation states exactly this, with these clauses.
