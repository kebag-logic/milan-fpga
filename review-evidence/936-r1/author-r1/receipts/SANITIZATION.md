# Packet sanitization

Scanned 133 files before indexing. Repository privacy/identity rules: zero findings.
Host home and workspace paths replaced with role placeholders; 40-character commit
identifiers shortened to eight characters. Binary SHA-256 values remain intact.
Every retained file is text and at most 200,000 bytes. Large logs and image binaries
are represented by original byte size and SHA-256, with excerpts where needed.
No toolchains, installed packages, virtual environments or tree exports are included.
The final index is generated from the sanitized files actually present, not a planned list.
