3. Set the declared value to it, derived from the format parameters, not mirrored as a constant.
4. Add a suite case that pins the TSpec value against the PDU size, with a planted mutant.
5. Run every gate the change touches, all rc 0.
6. STOP if the derived value differs from the specified one and the difference cannot be traced.
