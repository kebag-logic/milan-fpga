S4's bound follows from the actual listener, not merely the scenario exit status. With transactions and talker events masked in both valid and ready directions, START/STOP valid masked, and listener expiries excluded, only X_INIT, X_IDLE and X_PRELOAD are reachable before release. The holder captures START/STOP independently of the main FSM, so gating that valid is necessary. Its `ready` is the completion at `strq_done_r`, not request admission. Shared hard reset clears pending/busy/done/fail, and no presented request can fill the holder while owned. Passing completion/error unmasked therefore cannot complete an uncaptured request. This is consistent with the final page and T8, superseding the provisional generic handshake description.

The timer filter is justified by ownership: the pinned listener arms its timers only during excluded live walks; preload writes the record and issues A4 discovery, not a listener timer arm. The real timer service clears armed state on the same hard reset. Neither listener nor gate takes D3 rollback reset. The prototype counts injected listener-owner expiries, including saturation, rather than calling their silent loss normal. Product integration must preserve these reset/owner assumptions.

The transaction gate must also withhold upstream readiness and scoreboard admission, as T8 requires. The top's dispatch readiness and listener-scoreboard candidate already depend on listener readiness; inserting the paired gate at the prescribed boundary is coherent with that wiring. The event router keeps the first payload of each pending source until acknowledgement, counts repeated strobes as coalescing, and treats an acknowledge-edge strobe as a new event. It is not an unbounded event queue. The contract expressly retains that producer policy and makes no post-release fairness promise. The independent real-router probe confirmed held payload, counted coalescing, two-source delivery, release under backpressure, acknowledge-edge refire and reset; bypassing valid or ready separately failed `pop/take disagreement`.
