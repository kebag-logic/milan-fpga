# MicroCPU suite

This suite verifies arithmetic and execution behavior.

Run it directly:

```sh
make
```

The harness uses an independent C++ arithmetic model.

It covers directed and randomized operands.

See the [test developer guide](../../../docs/TEST_DEVELOPER.md).

Dated details remain [archived](../../../docs/history/v1/testing/UCPU_TEST_RECORD.md).
